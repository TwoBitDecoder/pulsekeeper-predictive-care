# Sync this project to GitHub

## Steps
- Open Project Settings → Git on desktop, or Chat mode → + → Project → GitHub on mobile.
- Connect GitHub and create the new private repository you approved.
- Confirm the project is linked; future Lovable commits will sync to its selected branch.

## Important
- This connection must be completed in Lovable’s interface; I can’t authorize GitHub or create the repository from chat.
- Git sync creates a new private repository and cannot attach this project to an existing repository.
- No application code changes are needed for Git sync.
